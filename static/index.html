    이 코스를 예약 흐름으로 넘겨볼까요?

    외부 예약사·결제·DB 저장 없이 MCP 액션 호출과 확인 절차만 검증합니다.

    검증 도구 실행 내역

    검증 방식

    추천보다 먼저 확인하는 것

    그럴듯한 설명보다 일정이 실제로 성립하는지를 먼저 봅니다.

    01

    Weather MCP

    날씨 조회 서버가 지역과 날짜 조건을 독립적으로 제공합니다.

    02

    Tour MCP

    관광 카탈로그와 장소 상세를 안정적인 place_id로 연결합니다.

    03

    Route MCP

    동선·비용·필수 조건을 결정론적으로 계산하고 검증합니다.

    04

    Booking MCP

    명시적 확인 뒤에만 외부 쓰기 없는 모의 예약 액션을 실행합니다.

    데이터 안내

    현재 제공 범위

    관광 정보는 로컬 교육용 카탈로그입니다. 장소 이름, 분류, 짧은 설명처럼 쉽게 변하지 않는 정보만 사용합니다.

    무료 공개판의 코스 생성은 같은 도메인 함수를 서버 내부에서 실행하며, 별도 프로세스 호출은 예약 버튼의 Booking MCP에서만 일어납니다. Booking MCP도 프로세스 메모리와 로그만 사용하는 모의 액션이며 개인정보를 저장하지 않습니다.
